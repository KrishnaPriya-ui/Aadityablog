About Aaditya Sharma

Web Application Security Engineer & Reverse Engineering Researcher

Executive Summary

I am a cybersecurity researcher specializing in Web Application Security, Bug Hunting, and Software Reverse Engineering. My work focuses on identifying complex vulnerability logic, dissecting compiled binaries, and reverse engineering existing software and games to understand their internal mechanisms and build custom tools/security solutions.

This technical blog serves as a public repository of my deep-dive research, tool-building walkthroughs, malware analysis breakdowns, and step-by-step security tutorials designed to help beginners and fellow security enthusiasts master technical fundamentals.
